# 安装教程

[中文首页](../README.zh-CN.md) · [English guide](INSTALL.md)

## 安装前

使用 Chromium 118 或更新版本的 Chrome／Edge 桌面浏览器。先查看 [支持范围](../README.zh-CN.md#支持范围)，确认游戏入口与客户端构建。本工具是非官方客户端修改，可能导致账号限制或封禁，请自行承担风险。

不需要 Steam、管理员权限、Node.js、Python，也不需要运行命令行。

## 1. 下载并解压

打开 [Releases](https://github.com/Chaldeaaa/yakuman-fx/releases)，在 **Assets** 下下载 `yakuman-fx-v<版本号>.zip`。这是扩展安装包；GitHub 自动生成的 **Source code** 是完整源码仓库。

将 ZIP 解压到准备长期保留的位置，例如 `文档/Yakuman FX`。不要直接在压缩包里加载，也不要放在临时目录。如果尚无 Release，点击仓库的 **Code → Download ZIP**，解压后找到其中的 `extension/` 文件夹。

下一步选择的文件夹应当包含：

```text
Yakuman FX/
├── manifest.json
├── background.js
├── popup.html
├── icons/
└── ...
```

如果下载的是源码仓库，应选择里面的 `extension/` 子文件夹，而不是整个仓库的根目录。

## 2. 加载到浏览器

| 浏览器 | 地址栏输入 |
| --- | --- |
| Chrome | `chrome://extensions` |
| Edge | `edge://extensions` |

开启 **开发者模式**，点击 **加载解压缩的扩展**（不同浏览器中文翻译可能略有差异），选择包含 `manifest.json` 的文件夹。确认列表中出现 **Yakuman FX**，并且处于启用状态。可在浏览器扩展菜单中固定图标，方便打开。

加载后保留该文件夹，浏览器会从这里读取扩展。不同浏览器／用户配置需要分别安装。

## 3. 在大厅首次启用

打开 [支持的游戏入口](../README.zh-CN.md#支持范围)，等待进入大厅。打开 Yakuman FX 弹窗，点击 **Enable & Reload**，确认当前处于大厅，游戏会自动刷新。

启动时浏览器会短暂显示调试提示。等待扩展状态变为：

```text
Native effects loaded. Debugging disconnected.
```

这表示原生特效已加载，调试连接已断开。图标上的标记应为 **ON**；“Temporary hook installed” 只是中间状态。

启用偏好会保存，以后加载游戏时自动生效。右上角齿轮打开设置，可选择 English／简体中文，以及浅色／深色／跟随系统主题，两项偏好都会保存。**不要在对局中启用或刷新。**

## 4. 恢复与卸载

点击 **Restore Default**，关闭未来的自动启用。随后在大厅刷新游戏，移除当前页面已加载的修改。

完全卸载时，在浏览器扩展管理页移除 Yakuman FX，并刷新游戏。移除扩展后，即可删除安装文件夹。

## 5. 更新

关闭游戏，将新版发行包解压后的扩展文件覆盖到原安装文件夹。返回扩展管理页，点击 Yakuman FX 的 **重新加载** 按钮，再打开游戏。

保持相同的文件夹位置，让浏览器继续使用同一个安装。更新无需卸载重装，目前没有自动更新功能。

## 遇到问题

在扩展管理页进入 **详情**，打开 **扩展程序选项／选项**，查看已保存的诊断。查看诊断不会重新连接调试器。常见情况见 [问题排查](../README.zh-CN.md#常见问题)。

反馈时提供扩展版本、浏览器版本、游戏入口／构建、复现步骤和相关诊断。仅在愿意公开牌谱内容时分享牌谱。不要上传账号凭据、认证令牌或浏览器配置文件。

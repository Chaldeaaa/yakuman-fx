# Yakuman FX v0.2.12 — First preview release

Native yakuman animation presentation for supported Mahjong Soul web builds, with a new single-tile launch icon.

- Automatic activation after one-time setup, with Enable & Reload and Restore Default controls.
- Chinese, Japanese and English entry support with pinned resource verification.
- English / Simplified Chinese interface and Light / Dark / System themes.
- Saved startup diagnostics in Settings.

## Install

Download **yakuman-fx-v0.2.12.zip** below, extract it to a permanent folder, open `chrome://extensions` or `edge://extensions`, enable Developer mode, then choose **Load unpacked** and select the extracted folder containing `manifest.json`.

Open the supported game in the lobby, open Yakuman FX, and choose **Enable & Reload**. Do not reload during a match. No command-line window or separate launcher is required.

The automatically generated source archives are for source distribution; the named extension ZIP is the installable package. `SHA256SUMS.txt` verifies the extension ZIP.

## Preview limitations

Chinese replay animation/audio has been user-confirmed. Japanese/English startup has been verified in isolated Edge checks; regional replay and live-match playback remain unverified. Chrome playback should receive a fresh check before store submission. Only the exact builds listed in [compatibility documentation](https://github.com/Chaldeaaa/yakuman-fx/blob/main/docs/COMPATIBILITY.md) are supported; game updates may require a new extension release.

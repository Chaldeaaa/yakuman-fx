# Yakuman FX v0.3.0

<details open>
<summary>English</summary>

Native yakuman animations for supported Mahjong Soul web builds.

- Automatic activation after one-time setup, with Enable & Reload and Restore Default controls.
- Chinese, Japanese and English entry support with pinned resource verification.
- English / Simplified Chinese interface and Light / Dark / System themes.
- Verified resource caching for subsequent launches and saved startup diagnostics in Settings.

### Install

Download **yakuman-fx-v0.3.0.zip** below and extract it to a permanent folder.

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select the extracted folder containing `manifest.json`.
4. Open the supported game in the lobby, open Yakuman FX, and choose **Enable & Reload**.

Do not reload during a match. No command-line window or separate launcher is required.

The automatically generated source archives are for source distribution; download the named extension ZIP to install.

在受支持的雀魂网页版中启用原生役满动画。

- 一次设置后自动启用，提供“启用并刷新”和“恢复默认”操作。

### 安装

下载下方的 **yakuman-fx-v0.3.0.zip**，解压到一个长期保留的文件夹。

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的解压文件夹。
4. 进入受支持的游戏大厅，打开 Yakuman FX，点击 **启用并刷新**。

请勿在对局中刷新。无需保持命令行窗口打开，也无需额外启动器。

GitHub 自动生成的 Source code 压缩包用于分发源码；安装扩展请下载上述指定 ZIP。

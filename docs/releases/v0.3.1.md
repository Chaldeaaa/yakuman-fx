# Yakuman FX v0.3.1

<details>
<summary>English</summary>

Native yakuman animations for supported Mahjong Soul web builds.

- Clearer status messages and recovery guidance.
- Check for updates in Settings, with manual installation instructions.
- Enhanced safety and reliability.

### Install

Download **yakuman-fx-v0.3.1.zip** below and extract it to a permanent folder.

1. Open `chrome://extensions` or `edge://extensions` and enable **Developer mode**.
2. Choose **Load unpacked** and select the folder containing `manifest.json`.
3. In the game lobby, open Yakuman FX and choose **Enable & Reload**.

To update an existing installation, extract the ZIP into the same extension folder and click **Reload** in the browser extension manager. Refresh the game only in the lobby.

### 安装

下载下方的 **yakuman-fx-v0.3.1.zip**，解压到一个长期保留的文件夹。

1. 打开 `chrome://extensions` 或 `edge://extensions`，开启 **开发者模式**。
2. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
3. 在游戏大厅打开 Yakuman FX，点击 **启用并刷新**。

更新已有安装时，将 ZIP 解压并覆盖原扩展文件夹，然后在浏览器扩展管理页点击 **重新加载**。请仅在大厅刷新游戏。
